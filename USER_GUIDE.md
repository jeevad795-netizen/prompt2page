## 💻 Using the Workspace

### Understanding the Layout

```
┌─────────────────────────────────────────────────────┐
│  Header (Timer, Participant Info, Submit Button)   │
├──────────────────┬──────────────────────────────────┤
│                  │  VS Code Editor                  │
│  ChatGPT         ├──────────────────────────────────┤
│  Simulator       │  Live Preview  │   Terminal      │
│  (Left Pane)     │  (When Run)    │   (Logs)        │
│                  │                │                  │
└──────────────────┴────────────────┴──────────────────┘
```

### Left Pane: ChatGPT Assistant 🤖

**Purpose**: Get coding help without using your own OpenAI account

**Features**:
- Pre-loaded with challenge context
- Suggested prompts for quick start
- Code examples for common patterns
- HTML, CSS, and JavaScript assistance

**How to Use**:
1. Click on suggested prompts OR type your own question
2. Press Enter or click the Send button
3. Review the code examples provided
4. Copy useful snippets to your editor

**Example Questions**:
- "Create a modern hero section for a campus website"
- "How do I make a responsive card grid?"
- "Add smooth scroll navigation"

### Right Pane: Code Editor 📝

**Features**:
- Three starter files already created:
  - `index.html` - Main HTML structure
  - `style.css` - Styling
  - `script.js` - JavaScript functionality
- Line numbers for easy reference
- Syntax highlighting
- Auto-completion
- Collapsible file explorer

**How to Use**:
1. Click on a file in the Explorer to open it
2. Edit the code in the Monaco editor
3. Switch between files using tabs
4. Toggle Explorer with the arrow button

**Keyboard Shortcuts**:
- `Ctrl+S` / `Cmd+S` - Save (auto-saves)
- `Ctrl+F` / `Cmd+F` - Find
- `Ctrl+Z` / `Cmd+Z` - Undo
- `Ctrl+Shift+F` / `Cmd+Shift+F` - Format code

### Running Your Code ▶️

1. Click the green **"Run"** button in the editor header
2. Watch the **Terminal** for build messages
3. Your project appears in the **Live Preview** pane
4. Preview updates automatically each time you run

**Terminal Messages**:
- 🟢 Green: Success
- 🟡 Yellow: Warnings
- 🔵 Blue: Information
- 🔴 Red: Errors

### Live Preview 📺

**Features**:
- Real-time rendering of your HTML/CSS/JS
- Sandboxed environment for safety
- Shows exactly how your project looks
- Updates when you click Run

**Tips**:
- Test frequently to catch issues early
- Check responsive design
- Verify all features work
- Ensure styling matches your vision

## ⏱️ Time Management

### Understanding the Timer

**Total Time**: 45 minutes

**Color Indicators**:
- 🟢 **Green** (45:00 - 15:01): Plenty of time
- 🟡 **Yellow** (15:00 - 5:01): Getting close
- 🔴 **Red** (5:00 - 0:00): Final minutes!

**What Happens**:
- Timer counts down in real-time (MM:SS format)
- Visible in the header at all times
- At 0:00, automatic submission occurs
- Editor locks when time expires

**Time Management Tips**:
1. **First 10 minutes**: Plan structure, use ChatGPT for templates
2. **Next 25 minutes**: Build and style your project
3. **Last 10 minutes**: Test, polish, and prepare to submit
4. **Final 5 minutes**: Final checks and submit

## 💡 Tips for Success

### Using ChatGPT Effectively

**Do's**:
- ✅ Use suggested prompts to get started quickly
- ✅ Ask specific questions
- ✅ Request code examples for specific features
- ✅ Learn from the provided examples

**Don'ts**:
- ❌ Don't just copy-paste without understanding
- ❌ Don't ask the same question repeatedly
- ❌ Don't expect it to build your entire project

### Coding Best Practices

1. **Start Simple**
   - Get basic structure working first
   - Add features incrementally
   - Test frequently

2. **Use Semantic HTML**
   - `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
   - Proper heading hierarchy (h1, h2, h3)
   - Descriptive class names

3. **Responsive Design**
   - Use flexbox or grid for layouts
   - Mobile-first approach
   - Test different screen sizes

4. **Clean Code**
   - Proper indentation
   - Comments for complex sections
   - Consistent naming conventions

### Time-Saving Techniques

1. **Use ChatGPT for boilerplate**
   - Navigation bars
   - Card layouts
   - Hero sections

2. **Focus on Core Features**
   - Implement required features first
   - Polish if time permits
   - Don't over-complicate

3. **Test Early, Test Often**
   - Run code every 5-10 minutes
   - Catch errors quickly
   - Verify layout works

## 🐛 Troubleshooting

### Common Issues

**Issue**: Preview not showing
- **Solution**: Click the Run button to generate preview

**Issue**: Code not updating
- **Solution**: Click Run again after making changes

**Issue**: JavaScript errors
- **Solution**: Check Terminal for error messages

**Issue**: Styling not applied
- **Solution**: Ensure CSS file is linked in HTML

**Issue**: Timer expired
- **Solution**: Project auto-submitted, editor locked
